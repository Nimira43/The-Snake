# 🐍 The Snake — CRT Arcade Edition

A retro‑styled browser game built with vanilla JavaScript and CSS, featuring:

- Dynamic CRT scanline effects
- Glitch‑break pulses
- Randomised background music with fade‑in/fade‑out transitions
- Maze obstacles
- Safe‑spawn logic and fair start delay
- Smooth gameplay loop
- Modular code structure
- Full sound system (pickup, game over, randomised BG tracks)

This project recreates the feel of a dying 1980s arcade cabinet — drifting scanlines, phosphor glow, glitch bursts, and crunchy sound effects.

---

## 🎮 Features

### ✔ CRT Visual Effects

- Strong scanlines with downward drift
- Glitch‑break overlay
- Flicker animation

### ✔ Audio System

- Random background track each game start
- Smooth fade‑in / fade‑out transitions
- Pickup and game‑over sound effects
- Supports `.mp3`, `.wav`, `.ogg`

### ✔ Gameplay

- Procedurally generated maze
- Safe spawn zone
- 1‑second “Get Ready” delay
- Smooth movement and collision detection
- Score tracking

---

## 🚀 Running the Game

1. Clone or download the repository  
2. Open `index.html` in a browser  
3. Enjoy the CRT‑meltdown arcade chaos  

For best results, run using a local server (VS Code Live Server, Python `http.server`, etc.)
